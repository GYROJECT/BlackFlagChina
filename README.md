# 黑旗中国网 BlackFlagChina

中国无政府主义协会面向中国境内社会性与组织化无政府主义者的公共资料与宣传空间。  
以清晰、克制、易读的方式整理文章、新闻、书籍与视觉素材。

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

构建产物在 `dist/`，可直接用于 GitHub Pages。

仓库地址：https://github.com/GYROJECT/BlackFlagChina

GitHub Pages 预计地址：https://gyroject.github.io/BlackFlagChina/

## 内容结构

内容目前集中在 `src/data/content.ts`，后续可拆成 Markdown 文件。

已从 Notion「黑旗中国网」迁入：首页结构、部分文章列表、书籍分类索引样例、关于与联系页。
书籍与文章全文将按页面继续补全。
